

## Badge Management Location

Based on the codebase, badge creation for coaches is already built and located at:

**Gamification page → Badge Management tab**

Navigation path: **Sidebar → Gamification** (`/gamification`)

The `Gamification.tsx` page includes a "Badge Management" tab that renders the `BadgeManagement` component, where coaches can:

- Create badges (name, type, emoji/uploaded icon, description, assignment rules)
- View all badges in a table
- See award counts
- Delete badges

No changes are needed — the feature exists. The coach just needs to navigate to **Gamification** in the sidebar.
